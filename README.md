PLAY AND LEARN — AI Educational Content
An independent project exploring AI-assisted educational video production for children.

PLAY AND LEARN is a personal content-creation project focused on producing short, English-language educational videos for young children. The project explores how generative AI tools can support ideation, prompt development, visual storytelling, and audiovisual production.

Project goals
Create simple, engaging educational videos for young children.
Experiment with generative AI tools for audiovisual content.
Develop and refine prompts, scripts, and production workflows.
Explore educational storytelling and age-appropriate presentation.
Build a digital content channel and learn from audience feedback over time.
Production approach
The videos documented here are designed around short scenes, simple learning objectives, repetition, direct questions, and clear on-screen English text. Production requirements and character continuity are documented individually for each video.

Tools
Google Flow: used for AI-assisted video creation, as specified for the current videos.
Prompt engineering: detailed scene descriptions, dialogue, visual constraints, and technical requirements.
YouTube Shorts: intended publishing format.
Other tools will be added here only when they are actually used in production.

Responsible production
The project aims to create original, child-appropriate educational content. Before publication, review each video for age suitability, visual and audio quality, subtitle accuracy, privacy, and applicable platform requirements for content made for children.
